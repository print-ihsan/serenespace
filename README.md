# SereneSpace - Platform Kesehatan Mental

**SereneSpace** adalah platform digital yang mengintegrasikan prinsip-prinsip mindfulness dengan teknologi modern untuk mendukung kesejahteraan mental. Website ini dirancang sebagai ruang aman bagi pengguna dalam mengelola kesehatan mental melalui berbagai fitur terapeutik seperti meditasi, pelacakan mood, dan soundscapes yang menenangkan.

---

## 🌟 Fitur Unggulan
- **Meditasi Terpandu** - Sesi mindfulness dengan berbagai tema dan durasi
- **Pelacakan Mood** - Monitor kondisi emosional harian dengan grafik visual
- **Seni Generatif** - Karya seni digital terapeutik untuk ekspresi kreatif
- **Soundscapes** - Koleksi suara alam dan musik relaksasi
- **Thought Dump** - Ruang privat untuk menumpahkan pikiran dan emosi
- **Mindfulness Timer** - Pengatur waktu meditasi dengan reminder

---

## 🛠️ Tech Stack yang Digunakan
- **HTML5** - Struktur dasar website
- **CSS3** - Styling dengan desain minimalis dan menenangkan
- **JavaScript** - Interaktivitas dan fungsionalitas frontend
- **GitHub Pages** - Hosting dan deployment gratis
- **Responsive Design** - Tampilan optimal di semua perangkat
